# Lista de Exercícios — Desenvolvimento Web (2º Semestre)

Projeto desenvolvido para a disciplina de **Desenvolvimento Web**, no curso de Desenvolvimento de Sistemas Multiplataforma (DSM) — Fatec São José dos Campos.

O projeto reune 6 atividades práticas em HTML, CSS e JavaScript, cada uma simulando um sistema de cálculo/gerenciamento diferente, com cadastro de registros e geração de relatório.

🔗 **Acesse o site publicado:** `https://pamelaiwabuchi.github.io/desenvol-web-ativ1/index.html`

---

## 📋 Atividades

| # | Atividade | Descrição |
|---|---|---|
| 1 | [Frete e Relatório](./1-frete-e-relatorio/index.html) | Calculadora de frete com base em combustível, distância, região e quantidade de peças, com geração de relatório consolidado. |
| 2 | [Folha de Pagamento](./2-folha-pagamento-e-bonus/index.html) | Cadastro de funcionários com cálculo de salário conforme categoria, turno e desempenho mensal. |
| 3 | [Controle de Produção e Estoque](./3-controle-producao-estoque-e-relatorios/index.html) | Registro de ordens de produção, controle de estoque e custos por tipo de produto. |
| 4 | [Reserva de Hotel](./4-reserva-hotel-tarifas/index.html) | Sistema de reservas com cálculo de diárias, tipo de quarto, temporada e café da manhã. |
| 5 | [Treinos Esportivos](./5-treinos-esportivos/index.html) | Cadastro de treinos semanais de jogadores, com controle de carga, intensidade e tipo de treino. |
| 6 | [Vendas e Comissões](./6-vendas-comissoes/index.html) | Registro de vendas com cálculo de comissão por vendedor, região e tipo de cliente. |

Cada atividade possui sua própria estrutura de `index.html` + `script.js`, mantendo os arquivos organizados por pasta.

---

## 🎯 Requisitos atendidos

### JavaScript
- ✅ **Estruturas de decisão** (`if / else`, `switch`) — aplicadas na lógica de cálculo de cada atividade (ex: definição de preço por região, categoria ou tipo de produto).
- ✅ **Comandos de repetição** (`for`) — usados para percorrer os registros cadastrados e gerar os relatórios (totais, médias, maior/menor valor).
- ✅ **Funções** (`function`) — cada atividade possui funções dedicadas para adicionar registros e gerar o relatório final.

### CSS / Layout
- ✅ Layout organizado com espaçamento, alinhamento e paleta de cores consistente (cada atividade tem uma cor de destaque própria).
- ✅ Tipografia com fonte Google Sans, aplicada em todas as páginas.
- ✅ Menu de navegação fixo no topo, presente em todas as páginas, dando acesso à Home e a todas as atividades.
- ✅ Site responsivo — testado em celular e desktop, com reorganização automática de menu, formulários e botões.

---

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura semântica das páginas
- **Tailwind CSS** (via CDN) — estilização e responsividade
- **JavaScript** — lógica de cálculo, validações e geração de relatórios
- **GitHub Pages** — hospedagem do projeto
